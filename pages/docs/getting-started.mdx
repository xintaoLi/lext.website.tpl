# 快速开始

这个指南将帮助你快速了解如何使用和开发这个站点。

## 本地开发

首先，安装依赖：

```bash
npm install
```

然后启动开发服务器：

```bash
npm run dev
```

打开浏览器访问 [http://localhost:3000](http://localhost:3000)。

## 创建内容

### 添加新页面

在 `pages` 目录下创建新的 `.mdx` 文件，例如：

```markdown
# 我的新页面

这是页面内容。
```

### 配置导航

编辑 `_meta.js` 文件来配置侧边栏导航：

```javascript
export default {
  intro: '介绍',
  'getting-started': '快速开始',
  'your-new-page': '你的新页面'
}
```

## 构建部署

构建静态站点：

```bash
npm run build
```

构建完成后，静态文件将输出到 `out` 目录，可以部署到任何静态托管服务。
