欢迎来到我的博客！这是使用 Nextra 和 Markdown 编写的第一篇文章。

## 为什么选择 Nextra？

Nextra 是一个强大的静态站点生成器，它有以下优点：

1. **简单易用** - 只需要会 Markdown 就能创建漂亮的文档
2. **功能丰富** - 支持代码高亮、搜索、暗色模式等
3. **性能优异** - 基于 Next.js，构建速度快，加载速度快
4. **可定制性强** - 可以轻松自定义主题和样式
